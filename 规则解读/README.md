## 本组相关的关键条款（v0.1 摘录）

**珠走玉盘组别描述**

- 自制球形机器人，在光电信标场地内完成光电信标检测与通过
- 光电信标规格参见《光电信标系统规格说明》
- 运动控制主体在一个透明塑料壳体内，球形壳体以滚动方式运行
- 头部通过磁铁吸附在壳体外部，并能通过滑动保持在外壳上部
- 头部中安装信标检测传感器，通过无线方式与壳内主体通讯
- **壳内主控部分没有信标检测传感器**
- 传感器：摄像头、光电管；主控：NXP RT1180；车模：自制；队伍：三人

**共用场地关系**

珠走玉盘与牵云逐光共用光电信标场地。两组可共建场地、共用信标灯，是省钱的唯一机会。

**器材与电路（全体组别通用）**

- 除最小系统核心板与允许的传感器模块内部板外，所有电路须自行设计制作
- 禁止带 MCU 的智能传感器，禁止"智能车比赛专用"成品模块
- PCB 须经嘉立创大赛指定通道免费打样，正面覆铜层标注学校 / 队伍 / 年份，丝印层含制作文件二维码；不满足者成绩无效
- 指定车模不得更改驱动电机与转向舵机的型号和数量；自制车模不限
- 电池规格不限，自行做好安全保护

**赛制（全体组别通用）**

- 成绩 = 完成时间 + 罚时，细则见《智能汽车竞赛比赛流程以及计分标准》（待发布）
- 无现场裁判自助式比赛，依靠视频留痕与 AI 审核溯源
- 全部车模须留标准发车接口，按《竞赛车模发车硬件和软件协议》实现
- 每校每组最多两支队伍；每校每组最多一支进国赛；每名同学最多两个竞速组别
