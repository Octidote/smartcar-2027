## 方案的三条主线

**一、结构本质是"三条无物理连接的路径"。** 球靠壳内质量块的重力矩驱动，头部靠磁力留在壳顶，感知靠无线回传。三条路径都要有量化余量：

- 磁吸力对头部重量的安全系数 ≥ 8 倍（头部 ≤ 180 g，装配后实测 ≥ 15 N）
- 无线单向时延 ≤ 8 ms
- 驱动轮压紧力 ≥ 整机重量的 60%（配重比 ≥ 0.6）

**二、感知走红外阵列，摄像头是备选。** RT1180 公开资料中无并口摄像头接口（Camera Interface 一栏为空），常见的 MT9V034 不能直连。信标红外是 850 nm、40 kHz 调制，用 TSOP 类红外接收头可直接解调，八只环形布置即可定向，功耗也远低于摄像头。

**三、控制分三层，高频环放在本地。** 头部姿态环在头部闭合（不经无线），球体速度/位置环在壳内闭合，任务层只负责给目标点。

## 已知的未知

细则未发布，以下五点必须自己做实验回答，不要等：

1. 透明球壳能否触发信标的光电检测
2. 判定方式是"遮挡""压过"还是"接近"
3. 场地尺寸与信标间距
4. 球径是否有隐含上限
5. 壳外是否允许加遮光环 / 配重附件

第 1 条最关键，实验结果直接决定要不要改整机结构。
