# 测试与实验

```
test/
├── 实验记录/    一次实验一个文件，含目的、方法、数据、结论
└── 标定数据/    参数标定的原始数据与拟合结果
```

## 实验记录格式

文件名：`YYYY-MM-DD-实验主题.md`

```markdown
# 2026-12-05 透明壳遮挡信标实验

## 目的
判断 3 mm 透明亚克力半球罩在信标灯上时，能否触发光电检测。

## 器材
- 半球：Ø200 亚克力，壁厚 3 mm
- 信标：往届信标灯 ×1，控制器 ×1
- 供电：12 V / 2 A

## 方法
半球扣在灯罩上，静置 10 s，记录控制器触发指示；重复 5 次。
对照组：不加半球，直接遮挡检测孔。

## 数据
| 次数 | 加半球 | 对照组 |
|------|--------|--------|
| 1 | 未触发 | 触发 |
| ... | ... | ... |

## 结论
5 次全部未触发，对照组 5 次全部触发。判定：透明壳无法触发，需加遮光环或头部下探。

## 下一步
1. 在半球赤道下方贴 30 mm 宽黑色哑光胶带，重复实验
2. 同步提 Q-02 确认遮光环是否合规
```

## 为什么要写这个

本届规则用 AI 对开发过程做查重与溯源。**失败的实验同样有价值**——它证明你们真的做了、真的想过。一份"试了三种方案都不行"的记录，比一份"一次就成功"的记录可信得多。

## 标定数据

命名：`YYYY-MM-DD-参数名.csv`，首行写列名与单位，第二行起是数据。拟合结果写在同名 `.md` 里，注明拟合方法与使用范围。
