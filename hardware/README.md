
版本号只增不改。改了设计就出新版本号，不要覆盖旧文件——旧的留着才能证明演进过程，AI 溯源看的就是这个。

## 出板前的合规检查

每次打样前逐项确认（漏一项就是成绩无效）：

- [ ] 正面覆铜层（top layer）有 **学校名称 / 队伍名称 / 参赛年份**，字高 ≥ 1 mm，装配后可见
- [ ] 丝印层有**制作文件链接的二维码**
- [ ] 板子通过**嘉立创大赛指定通道**下单（免费），不自己找厂
- [ ] 最小系统核心板上只保留 MCU / 时钟 / 电源 / 调试接口，其余外设全部经自制主板引出
- [ ] 没有使用带 MCU 的智能传感器，没有"智能车专用"成品模块
- [ ] 面积 < 1 cm² 或纯转接板可豁免标识，其余一律要标

## BOM 要求

BOM 里记四列：**位号 / 型号 / 数量 / 单价**，另加一列"是否已到货"。三人共用同一份，谁买了什么直接改，不要各记各的。
