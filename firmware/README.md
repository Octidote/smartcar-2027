# 固件

按两个物理刚体分成两个工程，因为它们之间只有无线链路，没有共享的时钟、电源和调试口。

```
firmware/
├── body/   壳内主体：RT1180 主控、驱动轮 FOC、球体 IMU、任务状态机、发车接口
└── head/   壳外头部：头部 MCU、三路全向轮驱动、八路红外、头部 IMU、无线从机
```

## 工具链

- 主体：MCUXpresso IDE / VS Code + MCUXpresso SDK，arm-none-eabi-gcc
- 头部：同族工具链，具体型号待定（见 `工作记录/提问台账.md` Q-06）
- 建议把两个工程放在**纯英文路径**下编译，避免中文路径导致的工具链报错

## 代码约定

- 控制环用固定周期定时器触发，不用 `delay` 凑时序
- 每个环的周期写在头文件里，一处定义：`CTRL_TASK_US`、`IMU_TASK_US`、`COMM_TASK_US`
- 所有可调参数集中在 `params.h`，且每个参数带单位注释
- 串口输出用二进制帧而不是 `printf`，比赛现场没时间看文本日志

## 数据记录

主体侧开一个 200 Hz 环形缓冲区，记录：时间戳、驱动轮电流、编码器、球体四元数、目标点、头部姿态、链路质量。跑完导出 CSV 到 `test/实验记录/`，这是调试时唯一能复盘的东西。
